# 🧩 Claude Skills

[← Back to README](../README.en.md) · 🌐 [日本語版](./claude-skills.md)

Skills callable from Claude / Claude Code to reuse domain-specific workflows.

| Skill                          | Description                                                                                                                                                                                               | Links                                                               |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **pdf-trust-skill**            | Orchestrates the PDF family MCPs to audit PDF authenticity (signature verification, tamper detection, PAdES / PDF/A, legal cross-referencing) and returns a Trust Report with an explicit recommendation. | [GitHub](https://github.com/shuji-bonji/pdf-trust-skill)            |
| **pdf-publish-skill**          | Orchestrates the PDF family MCPs as a quality-gated delivery pipeline (write → read-back → verify) and delivers with a Publish Report.                                                                    | [GitHub](https://github.com/shuji-bonji/pdf-publish-skill)          |
| **pdf-read-skill**             | Read-orchestration skill for large or hard-to-read PDFs. Measures the document first (page count, tags, encryption, whether text can be extracted), then reads via the structural, narrowed-search, or image route.        | [GitHub](https://github.com/shuji-bonji/pdf-read-skill)             |
| **houki-research-skill**       | Orchestration skill for legal research across the houki-hub MCP family. Encodes the lookup order (statute → cabinet order → ministerial order → notice → PDF → case law) and regulated-profession safeguards. | [GitHub](https://github.com/shuji-bonji/houki-research-skill)       |
| **experience-to-s1000d** | Converts an experiential manual (experiential-manual-model JSON) into an S1000D CSDB (data modules, publication module, ICNs). Numbering, assembly and verification go through s1000d-writer-mcp and s1000d-verify-mcp; the user picks any remaining fix from the candidates | [GitHub](https://github.com/shuji-bonji/s1000d-stack/tree/main/skill/experience-to-s1000d-skill) |
| **s1000d-publish** | Builds S1000D data modules (descriptive, procedural, process, fault isolation) one at a time from a structured draft (title, paragraphs, steps, warnings, tables, references), verifies them and puts them in the CSDB. Returns a Publish Report including the reconciliation with the DML | [GitHub](https://github.com/shuji-bonji/s1000d-stack/tree/main/skill/s1000d-publish-skill) |
| **s1000d-review** | Reviews an S1000D data module from three angles — what a machine can judge (XSD, BREX, references, applicability), the BREX rules that need a human check, and the prose (glossary, writing rules) — and records the chosen findings in the CSDB as comment DMs | [GitHub](https://github.com/shuji-bonji/s1000d-stack/tree/main/skill/s1000d-review-skill) |
| **s1000d-translate** | Extracts only the human-readable text from a data module, translates it, scores it with xcomet-mcp, and re-applies it to a data module with the same DMC in the target language. Returns a Translation Report including the segments that could not be re-applied | [GitHub](https://github.com/shuji-bonji/s1000d-stack/tree/main/skill/s1000d-translate-skill) |
| **ai-design-advisor**          | Skill for generative-AI design decisions. Given a use case, it names what has not been decided and answers only within what the canonical notes cover, leaving missing input unfilled.                                    | [GitHub](https://github.com/shuji-bonji/ai-design-advisor)          |
| **factcheck-skill**            | Fact-checking skill for Claude Code / Cowork — evaluates information reliability scientifically.                                                                                                          | [GitHub](https://github.com/shuji-bonji/factcheck-skill)            |
| **media-literacycheck-skill**  | LLM skill that evaluates online information from a media-literacy perspective.                                                                                                                            | [GitHub](https://github.com/shuji-bonji/media-literacycheck-skill)  |
| **spec-compliance-skills**     | Cowork plugin for checking compliance against W3C / IETF specifications.                                                                                                                                  | [GitHub](https://github.com/shuji-bonji/spec-compliance-skills/)    |
| **deepl-glossary-translation** | Translation workflow for PDF specifications using DeepL with a shared glossary for term consistency.                                                                                                      | [GitHub](https://github.com/shuji-bonji/deepl-glossary-translation) |

> [!NOTE]
> **pdf-trust-skill** (intake), **pdf-publish-skill** (delivery), and **pdf-read-skill** (reading) orchestrate the [PDF family](./mcp-servers.en.md#-pdf-family) MCPs, **houki-research-skill** orchestrates the [houki-hub family](./mcp-servers.en.md#-houki-hub-family) MCPs, and **experience-to-s1000d**, **s1000d-publish**, **s1000d-review** and **s1000d-translate** orchestrate the [S1000D family](./mcp-servers.en.md#-s1000d-family) MCPs.
